# v8r5 base-policy SET failure

This record preserves the first clean-boot test of the external-client
base-TGP SET on the verified MECHREVO RTX 5080 Laptop. It is a negative result,
not an activation recipe.

## Sequence

The patched NVIDIA 615.71.09 open module initialized normally. NVIDIA DRM took
over the framebuffer, GNOME Shell started, and both displays were configured.
The semantic resolver then completed all of its discovery phases:

```text
op=0: unique topology, stock/current ceiling 175000 mW
op=1: armed, zero writes
op=2: three verified ceiling writes, current ceiling 250000 mW
```

The external RM client successfully read the base policy table:

```text
policy 2 current: 80000 mW
source 13:        210000 mW
source 14:         60000 mW
```

At `04:45:57.418825`, the policy-2-only SET returned status 98,
`NV_ERR_RESET_REQUIRED`. At the same instant the kernel recorded:

```text
Xid 62
_kgspRpcGspEventPmuHalted: Received signal from GSP that PMU has halted
Xid 154: recovery action changed to PF FLR
```

Eight seconds later GNOME Shell received Xid 109 (`CTX SWITCH TIMEOUT`) and
segfaulted in `libnvidia-eglcore.so.615.71.09`. The resulting display loss
occurred after the desktop had already loaded.

## Conclusion

The semantic address resolver and the three ceiling destinations were not the
immediate failure point. The failure was synchronous with control command
`0x2080e61b`, sent through the external RM client using a buffer inferred from
the successful `0x2080a61a` GET response.

The GPU was idle; no FurMark or other load was running. The log therefore does
not support a physical over-current explanation. It supports a firmware or RM
validation failure caused by an invalid or incomplete SET contract. A readable
GET layout must not be assumed to be a writable SET layout.

The installed activation service was disabled, and the v8 boot entry was
renamed to `CachyOS - NVIDIA Semantic Resolver (inspection only)`. Further
work must remain read-only until the SET ABI and its preconditions are derived
from an authoritative implementation or verified control flow.
